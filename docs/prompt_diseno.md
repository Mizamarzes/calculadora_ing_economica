# Prompt para diseñar la interfaz de la calculadora financiera

> Copia todo el bloque de abajo y pégalo en la herramienta de diseño / IA que vayas a usar.

---

Necesito que diseñes la interfaz de una **calculadora financiera para un curso universitario de Ingeniería Económica**. Una interfaz simple y facil de leer

## Qué debe resolver la calculadora

**1. Interés compuesto**

**2. Conversión de tasas**

**3. Indexación de tasas**

**4. Anualidad vencida**

**5. Anualidad anticipada**

**6. Anualidad perpetua**

## Requisitos funcionales que el diseño debe soportar

- Seleccionar claramente el tipo de operación antes de pedir datos.
- Mostrar **únicamente** los campos necesarios para la operación y la incógnita elegidas; los demás se ocultan o deshabilitan.
- Cada campo numérico debe mostrar su **unidad** (moneda, %, número de periodos) y, cuando sea una tasa, su **periodicidad** y su **modalidad** (vencida/anticipada).
- Aceptar **valores decimales**.

## Criterios de diseño

- Interfaz en **español**.
- Interfaz sencillas como las calculadoras convencionales
- Responsive
- Guiate de plataformas como symbolab
